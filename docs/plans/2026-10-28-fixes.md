# 實測問題修正（10/28）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正 Pi 實測發現的五個問題：附件長度檢查誤殺、刪原訊息遇 Unknown Message、看圖網頁網址改抓預覽圖、直書漫畫字幕區切到半欄、作品名稱缺中文。

**Architecture:** 五項彼此獨立，各自一個 Task，都在既有套件內小幅修改：`internal/pipeline`（下載、刪除、網址 fallback）、`internal/commands`（/search 附件下載）、`internal/recognize`（預覽網址取得、OCR 整張條件、trace.moe 組名）。不新增依賴、環境變數或指令。

**Tech Stack:** Go 1.27、discordgo v0.29.0、RapidOCR（Python worker，只在 Docker `test` 階段整合測試）。

**Spec:** 本規劃即需求來源（PM 交付、使用者已確認的修法，見各 Task 的「定案」）；背景：`CLAUDE.md`、`docs/plans/2026-10-19-image-url.md`。

## Global Constraints

- 不得引入付費 API、不新增依賴。
- `URLFetcher` 安全規則不可放寬（只 http/https、公開位址 80/443、Dialer.Control 檢查每一跳、`Proxy: nil`、25MiB、2 分鐘）。
- `go test ./...` 不連網、不需要 Python；真實截圖只在 `-tags rapidocr` 測試使用，缺圖 `t.Skipf`。
- `/search` 貼網址圖的規則不變（不受 Task 3 影響）。
- 任一張下載失敗仍是一張都不發、加 ❌（Task 3 的 fallback 失敗也一樣）。

## Review Focus

1. 附件長度：伺服器回 gzip（Go 自動解壓時 `resp.ContentLength == -1`）或沒有 Content-Length 時不可誤判截斷 → Task 1 `TestHTTPFetcher_NoContentLengthOK`。
2. Unknown Message 只對 code 10008 放寬；其他刪除錯誤（403、500）仍是處理失敗、加 ❌ → Task 2 `TestProcess_DeleteFails` 保持通過＋`TestProcess_DeleteForbiddenStillFails`。
3. 預覽 fallback 不可繞過 SSRF：預覽網址指向私有位址時必須失敗 → Task 3 `TestProcess_PreviewFallback_BlockedAddressFails`（用真正的 `newURLFetcher(allowOnly(srv))`）。
4. 預覽 fallback 只在「副檔名判定、實際是網頁（ErrNotImage）」時啟用；ErrTooLarge、ErrImageGone、連線錯誤不 fallback → Task 3 `TestProcess_PreviewFallback_OnlyOnNotImage`。
5. 新的「碰到上緣」條件不可讓一般字幕改走整張 → Task 4 單元測試（上緣 3px 不觸發）＋整合測試 `sub_pasted_cropped.png` 斷言。

### Task 4：字幕區文字框碰到上緣 → 改辨識整張

**資料結構確認：** 足夠。`OCRItem.Box` 是 RapidOCR 對「傳入影像」回傳的座標；傳入的就是 `PrepareForOCR` 產生的字幕區影像（已縮到寬 ≤ 640），所以 `y` 本來就相對於字幕區頂端（y=0 即裁切上緣），單位是縮放後的像素。不需改 worker 或 OCRItem。

**門檻建議（PM 請確認，見 Q6）：** `subtitleTopEdgePx = 2`（縮放後字幕區像素，框的 `y.lo ≤ 2` 即碰到上緣）。理由：RapidOCR 的 DBNet 偵測框會外擴後裁到影像邊界，被切斷的字通常 `y.lo` 就是 0；1280x874 的樣本字幕區縮放後約 640x152，2px 約 1.3%，與「高度 1%」相近但對小圖不會變成 0。
