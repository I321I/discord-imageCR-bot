## 需求摘要

使用者在 Pi 上實測時回報了三個問題，PM 另外從 log 裡找到兩個。共 5 項：

1. **貼圖後只加上 ❌、什麼都沒發**
   - log：`下載附件 image.png 失敗：downloaded size does not match attachment size（預期 219770 bytes，得到 315747）`。同一張圖兩次都是完全相同的這兩個數字。
   - 根因：Discord 附件記錄的 `Size`，和 CDN 實際提供的 bytes 不一定相同（剪貼簿貼上的 image.png）。原本「長度必須等於 Size」的檢查因此誤殺正常的圖。
2. **刪除原訊息時遇到 Unknown Message（10008）**：處理途中原訊息已經不存在，卻被記成處理失敗。
3. **看圖網頁（`img.verb.tw/view/x.jpg`）**
   - 網址的副檔名是 .jpg，實際卻是網頁，所以加上 ❌。
   - 使用者希望 Discord 有圖片預覽時，改下載預覽裡的圖。
4. **直書漫畫的圖片文字只讀到「是」**
   - 圖是橫的漫畫格，直書文字延伸到底部。字幕區只切到單字「是」，單字框被判定成橫書，所以沒有改成辨識整張。
5. **作品名稱沒有中文**：trace.moe 的 `anilist.title` 有 `chinese` 欄位，但程式沒有讀。使用者同時改了規則：有中文時只放中文，沒有中文就放日文和英文。
